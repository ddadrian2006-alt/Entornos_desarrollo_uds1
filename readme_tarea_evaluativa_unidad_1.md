# Tarea de Evaluación Práctica - Unidad 1

**Módulo:** Lenguajes de Marcas y Sistemas de Gestión de Información  
**Unidad 1:** Reconocimiento y Uso de Lenguajes de Marcas  

---

## 📌 Descripción del Proyecto
Este repositorio contiene la resolución de la tarea práctica de la **Unidad 1** del módulo *Lenguajes de Marcas y Sistemas de Gestión de Información*. 

El propósito de esta evaluación es demostrar el dominio de los conceptos fundamentales de los lenguajes de marcado, la sintaxis correcta en la creación de documentos XML bien formados y la estructuración semántica básica mediante HTML5.

---

## 📁 Estructura del Repositorio

```text
.
├── index.html          # Documento con la estructura semántica principal en HTML5
├── datos.xml           # Documento XML bien formado respetando las reglas de sintaxis
└── README.md           # Documentación general y guía de la tarea
```

---

## 🛠️ Tecnologías Utilizadas

* **XML (eXtensible Markup Language):** Para el almacenamiento, transporte y estructuración lógica de los datos.
* **HTML5:** Para la maquetación y marcado semántico de contenidos web.
* **Markdown:** Para la creación de la documentación del proyecto.

---

## ✅ Criterios de Evaluación Cumplidos

### 1. Documento XML
* **Prólogo XML:** Incluye la declaración de versión y codificación (`<?xml version="1.0" encoding="UTF-8"?>`).
* **Elemento Raíz:** Contiene un único nodo raíz que envuelve toda la jerarquía.
* **Buena Formación:** 
  * Cierre correcto de todas las etiquetas opened/closed.
  * Anidamiento jerárquico estricto.
  * Respeto a la sensibilidad entre mayúsculas y minúsculas (*case-sensitivity*).
  * Atributos correctamente entrecomillados.

### 2. Documento HTML5
* Declaración del tipo de documento (`<!DOCTYPE html>`).
* Sección de metadatos (`<head>`) con codificación de caracteres `UTF-8` y título descriptivo.
* Uso de etiquetas semánticas (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`).
